# Gin Routing Example

This example demonstrates how to use the [Gin web framework](https://github.com/gin-gonic/gin) as a router with Bails.

## Overview

This example shows how to:

- Set up Gin as the asset handler for a Bails application
- Create a middleware that routes requests between Bails and Gin
- Define API endpoints with Gin
- Communicate between the Gin-served frontend and Bails backend
- Implement custom Gin middleware

## Running the Example

```bash
cd examples/gin-routing
go mod tidy
go run .
```
